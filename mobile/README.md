# QuizCredo for Android

A React Native (Expo) app that opens https://quiz-credo.vercel.app/ in a full-screen WebView. The
game itself is the web app: shipping a new version of the site updates the app too, with no new
build.

What the native shell adds:

- **Back button**: Android's back goes through the site's history, so the site's own back rules
  (room routes, the quit dialog during questions) still apply. With no history left it closes the
  app.
- **Outside links** open in the phone's browser; only `quiz-credo.vercel.app` loads in the app.
- **Full screen**: the status bar is hidden and the site draws edge to edge, padding itself with
  `env(safe-area-inset-*)`. Only a WebView too old to report those insets gets native padding.
- **Splash** (`src/LaunchSplash.tsx`): it takes over from the native splash on the same frame. The
  stage lights come on behind the logo, and a glint runs over the letters while the site loads. Then
  the logo lands on the site's own logo, which the page reports once its image has loaded.
- **Errors**: a "no connection" screen with a retry button shows when the site can't load (in pt, en
  or es, from the phone's language).
- **Sounds** (narrator, game audio) play without a tap on the page.

## Running

```bash
cd mobile
npm install
npm start            # Metro; open in Expo Go or a development build
npm run android:build # builds and installs a debug APK (needs the Android SDK, see below)
npm run typecheck
```

The build finds the Android SDK through `ANDROID_HOME`. Android Studio installs it in
`~/Android/Sdk` without setting that variable, which fails with "SDK location not found". In fish:

```fish
set -Ux ANDROID_HOME $HOME/Android/Sdk
fish_add_path $ANDROID_HOME/platform-tools $ANDROID_HOME/emulator
```

`android/` is generated by `expo prebuild` / `expo run:android` and is not committed: native
settings live in `app.json`.

Gradle must run on a full JDK (with `javac`), not a JRE. Some native modules compile with whatever
Java runs Gradle, and fail with "does not provide the required capabilities: [JAVA_COMPILER]" on a
JRE. The JDK 17 that Gradle downloads into `~/.gradle/jdks` works:

```fish
set -Ux JAVA_HOME (ls -d $HOME/.gradle/jdks/eclipse_adoptium-17-* | head -1)
```

After changing icons, the splash image or anything else in `app.json`, regenerate `android/` with
`npx expo prebuild --platform android`.

The debug build loads its JavaScript from Metro, so it only opens while the computer runs it. For an
APK that runs on its own (install it on any phone):

```bash
cd mobile/android
./gradlew app:assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a
# → android/app/build/outputs/apk/release/app-release.apk
```

It is signed with the debug key. That's fine for installing by hand, but the Play Store needs your own
keystore (https://reactnative.dev/docs/signed-apk-android).

For a release APK/AAB without a local Android SDK, use EAS Build:
`npx eas-cli@latest build --platform android`.
